Overview

How information flows

Rounded boxes are code files, coloured by status; grey boxes are files or folders they write; dashed boxes are inputs nothing in the repo writes. Hover or focus a file to light up only its inputs and outputs; click it to jump to its block diagram. Edges come from paths found in the code, so a path built at runtime from user input can be missing.

Run order

The order shell scripts invoke things in. Conditional steps run only when a check in the script passes.

File by file

Each file is drawn as its blocks in file order, covering every line. The coloured edge says what kind of work a block does; red arcs on the left are calls between functions in the same file (caller → callee); dashed violet tags are functions the block uses from elsewhere in the repo. Line ranges, calls and imports come from the syntax tree.
